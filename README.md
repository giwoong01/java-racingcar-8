## 기능 요구 사항 정리

자동차 경주 게임을 구현한다.

- 사용자는 n대의 자동차에게 이름을 부여한다.
- 부여된 자동차의 이름은 쉼표(,)를 기준으로 구분한다.
- 부여된 자동차의 이름은 5자 이하만 가능하다.
- 자동차가 전진할 때 자동차 이름도 같이 출력한다.
- 사용자는 몇 번의 이동을 할 것인지 입력한다.
- 자동차가 전진하는 조건은 0에서 9 사이에서 무작위 값을 구한 후 무작위 값이 4 이상일 경우이다.
- 자동차 경주 게임을 완료한 후 누가 우승했는지 알려준다.
- 우승자는 한 명일 수 있고, 여러 명일 수 있다.
- 우승자가 여러 명일 경우 쉼표(,)를 이용해 구분한다.

## 목표

- 1주차 공동 피드백 신경쓰기
- 프로그래밍 요구사항 잘 지키기
- 스스로 고민하고 생각하기
- 의미있는 코드 작성하기

## 구현할 기능 목록

- [x] 사용자
    - [x] 자동차 이름을 입력 한다.
        - 자동차의 이름은 쉼표(,)를 기준으로 구분한다.
        - 자동차의 이름은 5자 이하만 가능하다.
    - [x] 자동차가 몇 번의 이동을 할 것인지 입력한다.
        - 양의 정수값만 입력한다.

- [x] 자동차
    - [x] 이름을 부여받는다.
        - 5자 이하
        - n대의 경우 쉼표(,)로 구분
    - [x] 앞으로 전진 한다.
        - 조건은 4 이상일 경우

- [x] 출력
    - [x] 자동차 이름 입력 메시지
    - [x] 시도할 횟수 입력 메시지
    - [x] 실행 결과 (자동차 이름과 전진 표시)
    - [x] 최종 우승자 메시지

## 예외 상황

- [x] 자동차의 이름이 중복되는 경우
    - 자동차의 이름은 중복될 수 없습니다.
- [x] 자동차의 이름이 비어있거나 공백인 경우
    - 자동차의 이름은 비어있거나 공백일 수 없습니다.
- [x] 자동차의 이름이 5자 초과일 경우
    - 자동차의 이름은 5자를 초과할 수 없습니다.
- [x] 시도 횟수가 0 또는 음의 정수인 경우
    - 시도 횟수는 1 이상의 양수여야 합니다.
- [x] 시도 횟수가 문자를 입력하는 경우
    - 시도 횟수는 숫자여야 합니다.

## 테스트 코드
